# Tally
> 2026 - Fumec - Desenvolvimento Mobile: Projeto Integração
> FRONTEND

App open source gerenciador de cartões de fidelidade virtuais.

<br>

## Como executar o projeto localmente
- `git clone https://github.com/bt-glv/mobile-tally.git`.
- Criar e preencher o arquivo `src/environments/environment.ts` com as chaves de API do Firebase.
- `npm install` 
- `ionic serve`
